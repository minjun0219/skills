# 번역투·AI 티 패턴 (before → after)

강도: **강** = 한 번만 나와도 고친다 / **약** = 여러 번 겹치거나 다른 신호와 같이 나올 때만 고친다.
출처 표기는 `sources.md` 의 약칭이다. 예문은 기술 문서 쪽으로 골랐다.

---

## 1. 피동·무생물 주어

원칙: 행동하는 쪽을 주어로 세운다. 사람이 하는 일은 사람이(또는 생략된 독자가), 코드가 하는 일은 코드가 한다.

| 강도 | before | after |
|:--|:--|:--|
| 강 | 값이 검증되어집니다 | 값을 검증합니다 |
| 강 | 테스트가 실패하게 되는 원인 | 테스트가 실패하는 원인 |
| 강 | 사용자에 의해 트리거되는 버그 | 사용자가 일으키는 버그 |
| 강 | 설정이 완료되어야 합니다 | 설정을 마치세요 |
| 약 | 이 라이브러리는 데이터베이스 초기화를 수행해요 | 이 명령을 실행하면 데이터베이스를 초기화해요 |
| 약 | 이 API는 사용자에게 토큰 발급을 허용한다 | 이 API로 토큰을 발급받는다 |

- 단서: 도구 자체의 동작을 설명할 때는 도구를 주어로 써도 된다("`render` 는 조각 배열을 돌려준다"). [토스]
- 이중 피동 짝: 되어지다→되다, 해지다·시키다→하다, 불리는→부르는, 일컬어지는→일컫는. [MS]

## 2. 명사화·빈 동사

원칙: 동작은 동사로 쓴다. `수행/진행/실시/처리/완료 + 하다`는 거의 항상 빼도 뜻이 같다.

| 강도 | before | after |
|:--|:--|:--|
| 강 | 로그 파일을 삭제하는 작업을 수행합니다 | 로그 파일을 삭제합니다 |
| 강 | 시스템 모니터링 수행을 통해 성능 측정을 실시합니다 | 시스템을 모니터링해서 성능을 잽니다 |
| 강 | 리팩터링을 진행했다 | 리팩터링했다 |
| 약 | 구조적 변화와 효율화를 통한 안정성 확보 | 구조를 바꿔 더 안정적으로 만든다 |

- `-적/-성/-화` 가 한 문장에 둘 이상 겹치면 풀어 쓴다. [토스][im-not-ai F-4]

## 3. 직역 조사구

원칙: 관계는 조사 하나로 말한다.

| 강도 | before | after |
|:--|:--|:--|
| 강 | 이 API를 통해 데이터를 가져온다 | 이 API로 데이터를 가져온다 |
| 약 | 캐시에 대해 설명한다 | 캐시를 설명한다 |
| 강 | 성능에 있어서 중요한 점 | 성능에서 중요한 점 |
| 약 | 인증과 관련된 설정 | 인증 설정 |
| 약 | 로그에 기반하여 판단한다 | 로그를 보고 판단한다 |
| 약 | 재시도를 위해 큐에 넣는다 | 다시 시도하려고 큐에 넣는다 |
| 약 | 서버에서의 처리 | 서버가 처리하는 것 / 서버 처리 |
| 약 | 효과적인 읽기의 방법 | 효과적으로 읽는 방법 |

- `~에 대해`는 사람도 많이 쓴다. 한 문단에 셋 이상 몰릴 때만 고친다. [im-not-ai A-1]
- `-의`를 뺄 수 없는 경우도 있다("그의 설계"). 금지가 아니라 선호다. [새국어생활]

## 4. have·provide·support 직역

원칙: 영어 동사를 사전 뜻 하나로 옮기지 않는다. 한국어가 그 상황에 실제로 쓰는 말을 고른다.

| 강도 | before | after |
|:--|:--|:--|
| 강 | 이 함수는 세 개의 인자를 가지고 있다 | 이 함수는 인자가 셋이다 |
| 강 | 배경 지식을 가지고 있어야 한다 | 배경 지식이 있어야 한다 |
| 약 | 회의를 가졌다 | 회의를 열었다 |
| 약 | 이 패키지는 스트리밍 기능을 제공합니다 | 이 패키지로 스트리밍할 수 있습니다 |
| 약 | Go 도 지원합니다 | Go 에서도 쓸 수 있습니다 |

- `가지다`를 무조건 `하다`로 바꾸지 않는다. 명사에 맞는 동사가 따로 있다(열다·보내다·치르다). [국립국어원]

## 5. 개발 동사의 일상어 직역

원칙: 번역투를 피하려다 영어 동사를 일상어 하나로 1:1 옮기면 그것도 직역이다. 그 분야에서 실제로 쓰는 말을 쓴다.

| before | after | 원어 |
|:--|:--|:--|
| 다 쓰면 메모리를 놓는다 | 다 쓰면 메모리를 해제한다 | free / release |
| Node · Bun 에서 돈다 | Node · Bun 에서 실행된다 | runs on |
| 이 문서는 `main` 을 따른다 | 이 문서는 `main` 브랜치 기준이다 | tracks main |
| 태그로 낸다 | 태그로 출력한다 / 태그로 바꾼다 | emits |
| 붙든 것 | 아직 내보내지 않은 것 / 버퍼에 남은 것 | held |

- 판단 보류: 문서가 일부러 고른 말투일 수 있다. 점검할 때는 고치지 말고 묻는다.

## 6. 제목·내비게이션 직역

원칙: 제목은 그 페이지에 무엇이 있는지 말한다. 영어 문서 사이트의 관습 단어를 그대로 옮기지 않는다.

| before (원어) | after (예) |
|:--|:--|
| 개념 (Concepts) | 공통 규칙 / 먼저 알아 둘 것 / 실제 다루는 주제 이름 |
| 개요 (Overview) | 소개 / ○○란 / (첫 페이지는 제목 없이) |
| 시작하기 (Getting started) | 설치하고 써 보기 |
| 사용법 (Usage) | 쓰는 법 / 구체적 작업 이름 |
| 레퍼런스 (Reference) | API 목록 / 옵션 전체 |

- 실제로 담은 내용으로 짓는다. 담은 것이 여럿이면 가장 먼저 찾을 것을 쓴다.
- "개요", "시작하기"처럼 한국어 문서에서도 이미 굳은 말은 약한 신호다. 다른 직역 제목과 같이 나올 때 고친다.

## 7. AI 관용구·문장 틀

원칙: 포장 없이 명제를 바로 쓴다.

| 강도 | before | after |
|:--|:--|:--|
| 강 | 결론적으로, 이 방식이 더 빠르다 | 이 방식이 더 빠르다 |
| 강 | 이는 시사하는 바가 크다 | (삭제, 또는 무엇을 뜻하는지 구체적으로) |
| 강 | 미리보기가 기본인 이유다 | 그래서 미리보기를 기본으로 켰다 |
| 강 | 크게 세 가지로 나눌 수 있다. 첫째, … | (도입구를 빼고 바로 나열) |
| 약 | 눈여겨볼 것은 세 가지다 | 세 가지를 보면 된다 |
| 약 | 핵심은 캐시 무효화다 | 캐시 무효화가 문제다 |
| 강 | 단순한 변환기를 넘어 브릿지로 | 변환기가 아니라 브릿지다 (한 번만) |
| 약 | A가 아니라 B다 / A인가, B인가 | 문서에 한 번이면 둔다. 두 번 넘게 반복되면 나머지는 평서문으로 |

## 8. 문장부호·서식

원칙: 문장부호는 한국어 문장에 필요한 만큼만 쓴다.

| 강도 | before | after |
|:--|:--|:--|
| 강 | 정규화하고, 렌더하며, 나눈다 | 정규화하고 렌더해서 나눈다 |
| 강 | 넘긴다 — 고치고, 이스케이프하고, 나눠서 | 고치고 이스케이프한 뒤 한도에 맞게 나눠서 넘긴다 |
| 약 | 문단마다 줄표(—)로 붙인 부연 | 쉼표·괄호·별도 문장으로 |
| 약 | 문장마다 **볼드** | 문단에서 정말 중요한 한 곳만 |
| 약 | 매번 붙는 괄호 영어 병기 `정규화(normalization)` | 처음 한 번만 |
| 강 | 산문 문서의 이모지 머리표 | 뺀다 |

- 연결어미(-고/-며/-지만/-면서/-아서/-어서) 바로 뒤 쉼표는 LLM 한국어에서 가장 강하게 갈리는 신호다. [KatFishNet]
- 줄표 뒤에 행위를 나열하는 꼴은 영어 분사구문(`, fixing, escaping, and splitting`) 구조다. 동사 순서대로 한 문장에 넣는다.
- 원래 있던 줄표를 전부 지우지는 않는다. 문장마다 붙어 있을 때만 줄인다.

## 9. 헤지·형식명사·기타

| 강도 | before | after |
|:--|:--|:--|
| 약 | ~할 수 있을 것으로 보인다 | ~할 수 있다 / ~로 보인다 (완곡은 하나만) |
| 약 | 다음 릴리스에 나가는 것이다 | 다음 릴리스에 나간다 |
| 약 | 출력이 갈 곳. (명사구로 끝난 정의문이 계속됨) | 출력을 보낼 곳이다. (표 칸 안이면 명사구 그대로) |
| 약 | 에이전트들이 쓴 문서들 | 에이전트가 쓴 문서 |
| 약 | 지금 렌더하고 있다 | 지금 렌더한다 |
| 약 | 그는 / 그녀는 / 이는 / 이를 반복 | 생략하거나 명사를 다시 쓴다 |

- `~할 수 있다`를 단정으로 바꾸지 않는다. 반복될 때 일부만 다른 꼴로 바꾼다.
