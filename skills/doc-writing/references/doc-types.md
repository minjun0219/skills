# 문서 유형별 출발점

정해진 유형의 문서를 쓸 때 읽는다. 아래 표는 출발점이다. 정해진 양식이 있으면 양식이 먼저고, 쓸 내용이 없는 섹션은 만들지 않는다. 표에 없는 유형은 `SKILL.md`의 "쓰기 전에 정할 것"으로 독자와 읽는 방식을 정한 뒤 가장 가까운 행을 따른다.

| 문서 | 맨 앞 | 이어서 | 주의 |
|:--|:--|:--|:--|
| 작업 결과 보고 | 무엇이 바뀌었고 결과가 어떤지, 결과의 확신을 바꾸는 미확인 사항 | 독자가 정할 것, 위험, 결과와 별개인 확인 사항 | 작업 순서(과정 로그)는 요청이 있을 때만 쓴다 |
| 채팅 답변 | 질문에 대한 답 | 이유, 필요하면 예 | 한 화면에 다 들어가면 제목을 쓰지 않는다 |
| PR 설명 | 무엇을 왜 바꿨는지 두세 문장 | 리뷰어가 볼 곳, 테스트 방법, 위험 | 파일별 변경 나열보다 의도가 먼저다 |
| 설계 문서, ADR | 결정 한 문장 (결정 전이면 열린 질문) | 맥락, 검토한 선택지(표), 근거, 결과와 위험 | 장단점 나열에서 멈추지 않고 판단을 쓴다 |
| 리서치 요약 | 결론과 확신의 정도 | 근거와 출처, 불확실한 점 | 조사 과정보다 알게 된 것을 쓴다 |
| README | 무엇이고 누구를 위한 것인지 | 빠른 시작, 참조 문서 링크 | 제목은 범주 이름으로 둔다 |
| 회의록, 상태 공유 | 결정된 것, 할 일(담당, 기한) | 논의 요약 | 개조식이 맞다 |
