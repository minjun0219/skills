# 변수가 들어가는 메시지

웹 UI·CLI·서버 메시지가 같이 쓰는 규칙이다. 문자열에 값이 끼워 들어가면 조사·단위·어순이 값에 따라 깨지기 쉽다.
`기계` 열은 나중에 스크립트로 검사하거나 고칠 수 있는지를 표시한다. **고침** = 규칙만으로 정답이 하나로 정해진다,
**검출** = 찾을 수는 있지만 고치는 데 문맥이 필요하다, **판단** = 사람이나 LLM이 정한다.

## 1. 문장 조각을 이어 붙이지 않는다

한 문장은 키 하나로 둔다. 조각을 이어 붙이면 어순이 다른 한국어로 옮길 수 없고, 조사도 고를 수 없다. [ICU]

| 기계 | before | after |
|:--|:--|:--|
| 검출 | `t('delete') + name + t('done')` | `t('deleted', { name })` → `"{name}을(를) 삭제했습니다."` |
| 판단 | `"Step " + n + " of " + total`을 옮겨 `"단계 3 / 5"` | `"{n}/{total} 단계"`처럼 한국어 어순으로 한 키에 |

- 변수 순서는 한국어 어순에 맞춰 바꿔도 된다. 번호 없는 `%s %s`처럼 순서를 못 바꾸는 형식이면 괄호로 푼다
  (`%s(위치: %s)에서`). [MS]
- 영어의 `{n, plural, one {…} other {…}}` 분기는 한국어에 필요 없다. CLDR에서 한국어 복수 범주는 `other` 하나다. [CLDR]
  `파일 {n}개` 한 꼴로 쓴다. 영어 `one` 분기를 옮겨 `파일 1개` 문장을 따로 두지 않는다.

## 2. 변수 뒤 조사

값이 받침으로 끝나는지 알 수 없으므로 조사를 고정할 수 없다. 우선순위는 이렇다.

1. **코드에서 받침을 계산한다.** `es-hangul`의 `josa(name, '을/를')`처럼 값을 보고 조사를 고른다. [es-hangul]
   영문·숫자로 끝나는 값은 읽는 소리로 받침을 정해야 한다(`API를`, `3이` = 삼이). 라이브러리가 이것을 처리하는지 확인한다.
2. **변수 뒤에 명사를 둔다.** 조사가 그 명사에 붙으므로 값과 무관해진다. `{name}을(를)` → `{name} 파일을`,
   `'%s'이(가)` → `'%s' 브랜치가`. git `ko.po`가 자주 쓰는 방식이다. [git]
3. **병기한다.** 번역 파일만 고칠 수 있으면 `을(를)`·`이(가)`·`은(는)`·`과(와)`·`(으)로`를 쓴다.
   `(으)로` 말고는 받침 있는 형태를 앞에 둔다. [MS]

| 기계 | before | after |
|:--|:--|:--|
| 고침 | `{name}를 삭제했습니다` (받침 있는 값이면 틀림) | `{name}을(를) 삭제했습니다` 또는 `josa` 계산 |
| 고침 | `{path}로 이동합니다` | `{path}(으)로 이동합니다` |
| 고침 | `{name}를(을)` (순서 뒤바뀜) | `{name}을(를)` |
| 판단 | `{count}이(가) 남았습니다` | `{count}개 남았습니다` (숫자면 단위를 붙여 조사를 없앤다) |

## 3. 숫자·단위·날짜

| 기계 | before | after | 근거 |
|:--|:--|:--|:--|
| 고침 | `{n} 개`, `{n} 건`, `{n} 명` | `{n}개`, `{n}건`, `{n}명` | 숫자와 어울리는 단위 명사는 붙여 써도 된다(맞춤법 제43항). UI에서는 붙인다. [국어원][MS] |
| 검출 | `%d 문서가 대기 중` | `문서 %d개가 대기 중입니다` | 숫자 변수 뒤에 단위가 빠지면 넣는다. [MS] |
| 고침 | `2026. 10. 16` | `2026. 10. 16.` | 숫자 날짜는 마지막 마침표까지 찍는다. [국어원] |
| 판단 | 화면에 `2026-10-16T09:00:00Z` | `2026. 10. 16. 오후 6:00` | 사용자 화면은 `Intl.DateTimeFormat('ko-KR')`, 로그·API는 ISO 8601. [MDN] |
| 판단 | `1000원` | `1,000원` | 화면 숫자는 세 자리마다 쉼표를 찍는 관행을 따른다. |
| 판단 | `Line %d` → `줄 %d` | `%d번 줄` | 한국어 어순으로. [MS] |

- 날짜·숫자는 문자열에 박지 않고 로캘 포맷터로 만든다. 서버가 보낸 숫자·시각을 클라이언트가 포맷한다.

## 4. 인용·표시

- 값이 이름·경로·브랜치처럼 문장과 구분돼야 하면 작은따옴표로 감싼다(`'main' 브랜치`). 직접 인용은 큰따옴표. [git][국어원]
- 감싼 따옴표 뒤 조사도 값의 받침을 따른다(`'main'으로`). 따옴표가 조사 고르기를 바꾸지 않는다.

출처 약칭은 `sources.md`에 있다.
