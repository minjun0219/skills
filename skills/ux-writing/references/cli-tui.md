# CLI·TUI 출력

터미널에 찍히는 한국어 문구다. 진행·성공·경고·오류·프롬프트·도움말이 여기에 든다. 값이 끼워 들어가는 문구는
`message-variables.md`도 읽는다. `기계` 열의 뜻은 그 문서 머리말과 같다.

## 문체

개발 도구는 **합쇼체 평서문 + 지시는 `-세요`**를 기본으로 한다. 저장소에 이미 한국어 출력이 있으면 그 관례가 먼저다.

| 출력 | 꼴 | 예 |
|:--|:--|:--|
| 상태·결과 (완전한 문장) | `~합니다` `~했습니다` | `설정 파일 3개를 만들었습니다.` |
| 사용자가 할 일 | `~하세요` | `'mytool login'을 먼저 실행하세요.` |
| 진행 중 표시 | `~하는 중…` 또는 명사형 | `패키지를 받는 중…` / `빌드 중…` |
| 진행 로그 한 줄 (여러 줄이 이어짐) | 명사형, 마침표 없음 | `src/index.ts 확인 완료` |
| y/N 프롬프트 | `~할까요?` 또는 `~하시겠습니까?` | `기존 파일을 덮어쓸까요? [y/N]` |
| 도움말의 옵션 설명 | 명사형이나 `~합니다`, 한 도구 안에서 하나로 | `출력을 끕니다` / `출력 끄기` |

- 근거: git `ko.po`는 합쇼체 평서문에 지시는 `-십시오`, VS Code 한국어판은 합쇼체에 지시는 `-세요`다. MS 한국어 가이드는
  `-십시오` 대신 `-세요`를 쓰고 `-십시오`는 약관·법률 문서에만 남긴다. [git][VS Code][MS]
- 해요체는 개발 도구 출력에서 드물다. 사용자층이 일반인인 TUI(예: 설치 마법사, 게임 런처)라면 해요체도 고를 수 있다.
  고르면 도구 전체를 그 체로 맞춘다.

## 규칙

1. **오류는 사람이 읽는 말로 다시 쓴다.** 무엇을 못 했는지, 왜인지, 어떻게 하면 되는지 순서로. 원래 오류(errno, 스택)는
   `--verbose`나 뒤쪽에 둔다. [clig][Google]
2. **가장 중요한 줄을 맨 끝에 둔다.** 터미널에서는 마지막 줄이 눈에 남는다. 같은 오류가 여러 번이면 머리글 하나 아래 묶는다. [clig]
3. **다음에 칠 명령을 그대로 보여 준다.** 명령은 작은따옴표나 백틱으로 감싸 복사할 수 있게 한다. 고친 명령을 묻지 않고 실행하지 않는다. [clig]
4. **상태를 바꿨으면 바꿨다고 말한다.** 성공 출력은 한 줄로 짧게. `-q`로 끌 수 있게 한다. [clig]
5. **오류 문구의 표준 구문을 통일한다.** [MS]

| 기계 | before | after |
|:--|:--|:--|
| 판단 | `Error: EACCES: permission denied, open '/etc/x'` | `'/etc/x' 파일에 쓸 권한이 없습니다. 'sudo chown $USER /etc/x'로 권한을 바꾸세요.` |
| 검출 | `파일 복사를 실패하였습니다` | `파일을 복사하지 못했습니다.` (Failed to …) |
| 검출 | `파일을 찾는데 실패` | `파일을 찾을 수 없습니다.` (Cannot find …) |
| 검출 | `설치 중 에러 발생함` | `설치하는 동안 오류가 발생했습니다.` (An error occurred while …) |
| 검출 | `설정이 업데이트되어졌습니다` | `설정을 업데이트했습니다.` |
| 고침 | `빌드 중..` / `빌드 중...` | `빌드 중…` (프로젝트가 `...`를 쓰면 그대로) |
| 판단 | `완료!`만 출력 | `배포했습니다: https://…` (무엇이 됐는지와 결과 위치) |
| 판단 | `계속하시겠습니까? (y/n)` 뒤 기본값이 불분명 | `계속할까요? [Y/n]` (기본값을 대문자로) |

- `실패`·`에러`는 명사로만 쓰고 동사 자리에서는 `~하지 못했습니다`로 쓴다.
  `오류`와 `에러`는 한 도구 안에서 하나로 통일한다.
- 능력이 없는 것은 `~할 수 없습니다`, 시도했다가 안 된 것은 `~하지 못했습니다`로 나눈다.

## 표시

- 색은 뜻이 있을 때만 쓴다. TTY가 아니거나 `NO_COLOR`가 비어 있지 않거나 `TERM=dumb`이면 끈다. 색만으로 뜻을 전하지 않는다
  (`오류:`·`경고:` 머리말을 함께 쓴다). [clig]
- 본 출력은 stdout, 진행·경고·오류는 stderr. 한국어로 바꿔도 이 구분은 그대로다. [clig]
- 이모지·기호(✓ ✗)는 절제한다. 쓰면 한 종류의 의미에 한 기호만.
- 한글은 터미널에서 두 칸을 차지한다. 열을 맞추는 표·진행 막대는 문자 수가 아닌 표시 너비로 계산한다.
- 기계가 읽는 출력(`--json`, 종료 코드, 로그 키)은 번역하지 않는다.
